
# 🎓 NextGen AI Academy

**Learn AI. Build Skills. Shape the Future.**

NextGen AI Academy is an AI-focused learning platform concept designed for students and young professionals who want to understand artificial intelligence, develop practical skills and build real-world projects.

🔗 **Live Demo:** https://nextgen-ai-academy.vercel.app/  
💻 **GitHub:** https://github.com/Manu1067/nextgen-ai-academy

## ✨ Features

- **Modern Landing Page:** A professional introduction to the academy and its learning philosophy.
- **Course Discovery:** Explore AI learning opportunities and course categories.
- **Structured Learning Journey:** Present learning paths for different skill levels.
- **Project Showcase:** Highlight practical, project-based learning.
- **Student Testimonials:** Illustrative testimonials demonstrating the intended experience.
- **Registration Interface:** Frontend registration experience for prospective learners.
- **FAQ Section:** Answers to common questions about the learning experience.
- **Responsive Design:** Adaptable layout for desktop, tablet and mobile devices.

## 🛠️ Technology Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
- Git and GitHub
- Vercel

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Manu1067/nextgen-ai-academy.git
cd nextgen-ai-academy
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## 🎯 Product Objective

The platform aims to make AI education more accessible through structured learning, practical projects and an engaging digital learning experience.
