# 🎓 NextGen AI Academy

### Build Your Future in the Age of AI.

NextGen AI Academy is a modern, responsive AI education landing page designed to introduce students, fresh graduates, and working professionals to practical artificial intelligence and emerging digital skills.

The platform presents structured learning opportunities, featured courses, hands-on projects, and a simple registration experience to help learners begin their AI journey.

---

## ✨ Key Features

- **Modern Landing Page:** Premium, responsive interface with an AI-inspired visual identity.
- **Featured Courses:** Explore courses covering AI fundamentals, Generative AI, Prompt Engineering, AI Automation, Machine Learning, and AI productivity tools.
- **Learning Journey:** A structured four-stage learning experience – Discover, Learn, Build, and Launch.
- **Target Audience Sections:** Dedicated content for students, fresh graduates, and working professionals.
- **Project Showcase:** Examples of practical AI projects learners can build.
- **Course Details:** Interactive course cards with learning objectives, prerequisites, and course information.
- **Registration Form:** User-friendly form with input validation and submission feedback.
- **FAQ Accordion:** Expandable frequently asked questions.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Manu1067/nextgen-ai-academy.git
   ```

2. Navigate to the project directory:

   ```bash
   cd nextgen-ai-academy
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal, usually:

   ```text
   http://localhost:5173
   ```
